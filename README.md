# 🚙 Belarus Car Price Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Automotive](https://img.shields.io/badge/Automotive-Belarus-blue.svg)

## 📖 Overview

Regression model for predicting used car prices in the Belarus market. Analyzes vehicle specifications, age, mileage, and condition for accurate price estimation.

## 🎯 Features

- Belarus market-specific pricing
- Vehicle depreciation analysis
- Brand comparison
- Market trend insights

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Belarus-Car-Price-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Price Factors

- Make, Model, Year
- Mileage, Engine Volume
- Transmission, Fuel Type
- Condition, Color
